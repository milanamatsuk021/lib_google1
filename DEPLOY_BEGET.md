# Инструкция по публикации приложения на хостинге Beget

Ниже описано, как выложить приложение "Личная библиотека" на Beget двумя способами: полноценный PHP + MySQL и статическая React-сборка.

## Общие требования
- Доступ в панель управления Beget (https://cp.beget.com).
- Созданный сайт/домен (можно использовать технический `*.beget.tech`).
- Архив проекта с файлами `index.php`, `auth.php`, `book_actions.php`, `dashboard.php`, `db.php`, `db.sql`, а также статикой (`style.css`, `script.js` и др.).

## Вариант 1. Полноценное приложение (PHP + MySQL)
Используйте, если хотите работать с бэкендом и БД.

### Шаг 1. Подготовьте сайт
1. В панели Beget откройте раздел **«Сайты»** → **«Добавить»**.
2. Укажите имя сайта (например, `library`) и привяжите домен.
3. После создания у сайта будет папка вида `~/library/public_html` (путь уточните в файловом менеджере).

### Шаг 2. Создайте MySQL-базу и импортируйте схему
1. Перейдите в раздел **«MySQL»** → **«Добавить БД»**.
2. Введите имя базы (например, `library`) и пароль. Полное имя будет `вашлогин_library`, пользователь обычно совпадает.
3. После создания нажмите на иконку **phpMyAdmin (P)** рядом с базой.
4. В phpMyAdmin выберите вашу базу слева, перейдите во вкладку **SQL** и вставьте содержимое файла `db.sql` из проекта. Нажмите **Go/Вперёд** для создания таблиц.

### Шаг 3. Настройте подключение в `db.php`
1. На локальной машине откройте `db.php`.
2. Замените параметры на данные из панели:
   ```php
   $host = 'localhost';
   $db   = 'вашлогин_library';
   $user = 'вашлогин_library';
   $pass = 'ПАРОЛЬ_ОТ_БД';
   ```
3. При необходимости укажите кодировку `$charset = 'utf8mb4';` (по умолчанию уже задана).
4. Сохраните файл.

### Шаг 4. Загрузите файлы на хостинг
1. В панели Beget откройте **«Файловый менеджер»** или подключитесь по FTP/SFTP.
2. Перейдите в папку сайта `public_html` и удалите стандартный `index.html`, если он есть.
3. Загрузите все PHP-файлы из проекта (`index.php`, `auth.php`, `book_actions.php`, `dashboard.php`, `db.php`) вместе со статикой (`style.css`, `script.js`, `components/`, `services/` и т.п.).
4. Убедитесь, что права доступа оставлены по умолчанию (644 для файлов, 755 для папок).

### Шаг 5. Проверьте работу
1. Откройте домен в браузере. Должна отображаться форма входа/регистрации.
2. Зарегистрируйте тестового пользователя и убедитесь, что добавление/удаление книг работает.
3. При ошибках подключений проверьте лог `/var/www/USERNAME/data/logs/php_errors.log` и настройки `db.php`.

## Вариант 2. Статическая React-сборка (без бэкенда)
Подходит, если хотите разместить фронтенд без сервера и БД (данные будут храниться в localStorage).

### Шаг 1. Соберите проект локально
```bash
npm install
npm run build
```
После сборки появится папка `dist/` с готовыми файлами.

### Шаг 2. Загрузите сборку на Beget
1. В файловом менеджере откройте `public_html` сайта.
2. Загрузите **содержимое** папки `dist/` (файлы `index.html`, `assets/` и т.д.) напрямую в `public_html`.
3. Создайте рядом файл `.htaccess` для маршрутизации SPA:
   ```apache
   Options -MultiViews
   RewriteEngine On
   RewriteCond %{REQUEST_FILENAME} !-f
   RewriteRule ^ index.html [QSA,L]
   ```

### Шаг 3. Проверьте
Откройте домен: приложение должно работать как статический фронтенд.

## Полезные заметки
- Версию PHP можно сменить в разделе **«PHP»** панели управления (рекомендуется 8.1+).
- При использовании FTP убедитесь, что пассивный режим включён.
- Если нужны cron-задачи (например, очистка сессий), добавьте их в разделе **«Cron»**.
- Для HTTPS подключите бесплатный LetsEncrypt в разделе **«SSL»**.
