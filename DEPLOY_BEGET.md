# Инструкция по деплою на хостинг Beget

Здесь описано, как разместить ваше приложение "Личная библиотека" на хостинге Beget.

## Вариант 1: Полноценное приложение (PHP + MySQL)

Этот вариант подходит, если вы используете PHP файлы (`index.php`, `auth.php`, `db.php` и т.д.).

### Шаг 1: Подготовка домена
1. Зайдите в панель управления Beget.
2. Перейдите в раздел **"Сайты"**.
3. Создайте новый сайт (например, `library`).
4. Прикрепите к нему домен (можно использовать бесплатный технический домен вида `username.beget.tech`).

### Шаг 2: Создание Базы Данных (MySQL)
1. В главной панели перейдите в раздел **"MySQL"**.
2. Введите имя новой базы данных (например, `library`) и пароль.
   * *Обратите внимание: полное имя базы будет `вашлогин_library`*.
3. Нажмите **"Добавить"**.
4. Нажмите на иконку **"phpMyAdmin"** (буква P) рядом с созданной базой.
5. В phpMyAdmin выберите вашу базу данных (слева), перейдите во вкладку **"SQL"** (сверху).
6. Вставьте содержимое файла `db.sql` и нажмите **"Вперед"** (Go). Это создаст таблицы.

### Шаг 3: Настройка подключения (db.php)
На своем компьютере откройте файл `db.php`. Вам нужно заменить параметры подключения на те, что вы создали.

```php
<?php
$host = 'localhost'; 
$db   = 'вашлогин_library'; // Полное имя базы из панели Beget
$user = 'вашлогин_library'; // Обычно совпадает с именем базы
$pass = 'ВАШ_ПАРОЛЬ_ОТ_БД'; // Пароль, который вы задали в шаге 2
$charset = 'utf8mb4';

// ... остальной код подключения ...
?>
```

### Шаг 4: Загрузка файлов
1. В панели Beget перейдите в **"Файловый менеджер"**.
2. Найдите папку вашего сайта: `~/ваш_сайт/public_html`.
3. Удалите оттуда файл `index.html` (заглушку), если он есть.
4. Загрузите туда все ваши `.php`, `.css` и `.js` файлы.

Готово! Откройте ваш сайт в браузере.

## Вариант 2: React версия (Frontend only)

Если вы хотите выложить текущую React-версию (но она будет работать с локальным хранилищем браузера).

### Шаг 1: Сборка проекта
На вашем компьютере в терминале выполните:
```bash
npm run build
```
Это создаст папку `dist` (или `build`).

### Шаг 2: Загрузка на Beget
1. Зайдите в **"Файловый менеджер"** на Beget.
2. Перейдите в папку сайта `~/ваш_сайт/public_html`.
3. Загрузите туда **содержимое** папки `dist`.
4. Создайте файл `.htaccess` в папке `public_html` для корректной маршрутизации React:

**Содержимое .htaccess:**
```apache
Options -MultiViews
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteRule ^ index.html [QSA,L]
```
