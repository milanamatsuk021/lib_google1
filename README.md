# Документация проекта "Личная библиотека"

## О проекте
Приложение для учета прочитанных книг с возможностью ведения списка "Хочу прочесть", "Читаю" и "Прочитано", а также добавления личных рецензий.

## Документация по развертыванию
- **[Инструкция для хостинга Beget (PHP + PostgreSQL)](./DEPLOY_BEGET.md)** — Рекомендуемый вариант для полноценной работы.
- **[Инструкция для GitHub Pages](./README.md#2-как-опубликовать-приложение-на-github-pages)** — Для статической версии.

## 1. Структура Базы Данных (LocalStorage версия)

В текущей React-версии приложения используется **Client-Side Storage** (локальное хранилище браузера).

### Схема данных (JSON)

Все данные хранятся в виде JSON-строк под следующими ключами:

#### 1. Пользователи (`library_users`)
Массив объектов пользователей.
```json
[
  {
    "id": "uuid-string",
    "username": "user1",
    "passwordHash": "base64-encoded-string" 
  }
]
```

#### 2. Текущая сессия (`library_current_user`)
Объект пользователя, который в данный момент авторизован.

#### 3. Книги (`library_books`)
Массив объектов книг.
```json
[
  {
    "id": "uuid-string",
    "userId": "uuid-user-1",
    "title": "Название книги",
    "author": "Автор",
    "status": "Хочу прочесть",    
    "review": "Текст отзыва...",
    "createdAt": 1715000000000
  }
]
```

## 2. Как опубликовать приложение на GitHub Pages

GitHub Pages идеально подходит для этого приложения, так как оно является статическим.

### Пошаговая инструкция

#### Шаг 1: Подготовка
```bash
git init
git add .
git commit -m "Initial commit"
```

#### Шаг 2: Установка деплоера
```bash
npm install gh-pages --save-dev
```

#### Шаг 3: Настройка package.json
Добавьте в `package.json`:
1. `"homepage": "https://USERNAME.github.io/REPO",`
2. В скрипты: `"deploy": "gh-pages -d dist"`

#### Шаг 4: Публикация
```bash
npm run build
npm run deploy
```
