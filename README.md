# Документация проекта "Личная библиотека"

## 1. Структура Базы Данных (LocalStorage)

В текущей React-версии приложения используется **Client-Side Storage** (локальное хранилище браузера). Это означает, что данные не отправляются на удаленный сервер, а хранятся прямо в браузере пользователя.

### Схема данных (JSON)

Все данные хранятся в виде JSON-строк под следующими ключами:

#### 1. Пользователи (`library_users`)
Массив объектов пользователей.
```json
[
  {
    "id": "uuid-string",
    "username": "user1",
    "passwordHash": "base64-encoded-string" // В реальном проекте здесь должен быть настоящий хеш (bcrypt/argon2)
  }
]
```

#### 2. Текущая сессия (`library_current_user`)
Объект пользователя, который в данный момент авторизован.
```json
{
  "id": "uuid-string",
  "username": "user1",
  "passwordHash": "..."
}
```

#### 3. Книги (`library_books`)
Массив объектов книг. Связь с пользователем осуществляется через поле `userId`.
```json
[
  {
    "id": "uuid-string",
    "userId": "uuid-user-1",      // Внешний ключ (связь с пользователем)
    "title": "Название книги",
    "author": "Автор",
    "status": "Хочу прочесть",    // Enum: "Хочу прочесть" | "Читаю" | "Прочитано"
    "review": "Текст отзыва...",  // Опционально
    "createdAt": 1715000000000    // Timestamp
  }
]
```

## 2. Как опубликовать приложение на GitHub Pages

GitHub Pages идеально подходит для этого приложения, так как оно является статическим (не требует выполнения PHP или Node.js на сервере во время работы).

### Предварительные требования
1. Установлен **Node.js**.
2. Есть аккаунт на **GitHub**.
3. Создан **пустой репозиторий** на GitHub.

### Пошаговая инструкция

#### Шаг 1: Подготовка проекта
Откройте терминал в папке с проектом. Если вы еще не инициализировали git:
```bash
git init
git add .
git commit -m "Initial commit"
```

#### Шаг 2: Установка пакета для деплоя
Установите специальную утилиту `gh-pages`:
```bash
npm install gh-pages --save-dev
```

#### Шаг 3: Настройка package.json
Откройте файл `package.json` и добавьте следующие строки:

1. **Добавьте поле `homepage`** (в самом верху, замените `USERNAME` и `REPO` на свои):
   ```json
   "homepage": "https://USERNAME.github.io/REPO",
   ```

2. **Добавьте скрипты** в секцию `"scripts"`:
   ```json
   "scripts": {
     "predeploy": "npm run build",
     "deploy": "gh-pages -d dist"
   }
   ```
   *(Примечание: Если сборщик создает папку `build` вместо `dist`, замените `dist` на `build` в команде deploy).*

#### Шаг 4: Загрузка на GitHub
Свяжите локальный проект с репозиторием (если еще не сделали):
```bash
git remote add origin https://github.com/ВАШ_НИК/ВАШ_РЕПОЗИТОРИЙ.git
git branch -M main
git push -u origin main
```

#### Шаг 5: Публикация
Запустите команду деплоя:
```bash
npm run deploy
```

Эта команда автоматически:
1. Соберет оптимизированную версию приложения.
2. Загрузит её в специальную ветку `gh-pages` в вашем репозитории.

После этого ваше приложение будет доступно по ссылке, которую вы указали в `homepage`.

---

### Важное примечание про PHP версию
Если вы решите вернуться к версии на **PHP + PostgreSQL**:
1. **GitHub Pages работать не будет**, так как он поддерживает только статические сайты (HTML/CSS/JS).
2. Вам потребуется хостинг с поддержкой PHP (например, Beget, Timeweb, Reg.ru) или облачные платформы (Heroku, DigitalOcean, Render).
